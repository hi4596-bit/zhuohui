Git 发布与备份

本地后台负责编辑；Git 保存历史；GitHub Pages 只发布静态网站目录。

推荐发布流程

后台保存文件后，Git 提交并推送，网站由 GitHub Actions 自动发布。

在本地后台编辑
商品、颜色、首页模块分别保存到 data/ 下对应的 JSON 文件。
先本地预览
打开网站，检查图片、链接、手机布局，再决定是否发布。
运行项目根目录的 git-publish.bat
脚本会查看 Git 状态、暂存修改、创建提交并推送到当前分支。
GitHub Actions 发布
工作流只发布 zhuohui-floral-site/，不会把本地后台服务和管理工具部署到公开网站。

安全与限制

  • 本地后台仅绑定 127.0.0.1，不向局域网或公网开放。
  • GitHub Pages 不运行 Python 服务端程序；管理 API 仅在本机可用。
  • 公开仓库和 Pages 网站中的文件均可能被公众访问，请勿在 JSON 或 HTML 中存储密码、客户隐私或内部成本。
  • 上传图片会进入 Git 仓库并发布到网站，上传前确认图片可公开展示。
